# Sistema de Organização de Menus de Aplicação

Projeto Java simples para manipular uma árvore de menus via CLI.

## Estrutura

- `src/menu/MenuItem.java` - Representa um item de menu com submenus.
- `src/menu/MenuManager.java` - Contém as operações fundamentais de gerenciamento da árvore.
- `src/menu/Main.java` - Interface de linha de comando para executar as funcionalidades.

## Como compilar e executar

No terminal, execute:

```powershell
javac src/menu/*.java
java -cp src menu.Main
```
